# TheHive - Proyecto Integrador DAW 2

## Stack Tecnológico
- **Backend:** Strapi v5 (CMS Headless)
- **Frontend:** Astro + Tailwind CSS
- **Base de datos:** PostgreSQL
- **Servidor:** Nginx
- **Despliegue:** VPS (Hetzner)

## Estructura
- `/backend` - API Strapi
- `/frontend` - Aplicación Astro
- `/docs` - Documentación del proyecto
